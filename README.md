### v5.6
- **대사성 알칼리증 + HCO₃⁻>24 + AG 상승 시 HAGMA 과잉 판정 수정**
  - ΔHCO₃⁻ 음수 → Delta ratio 계산 불가 → HAGMA 확정 보류
  - 최종 카드: "대사성 알칼리증 + 호흡성 알칼리증 / Note: AG 상승, HAGMA 동반 가능성"
  - 플로우차트: HAGMA 칸 주황색(불확실) + "확정 보류" 표시
- **NAG 패턴 설명 개선** — HCO₃⁻·Cl⁻ 실제값 조합에 따른 4가지 패턴 구분
  - HCO₃⁻↑ Cl⁻↓ / HCO₃⁻↑ Cl⁻↑ / HCO₃⁻↑ Cl⁻ 정상 / HCO₃⁻↓ Cl⁻↑
- **Low AG 분류 추가** — AG < 6 mEq/L 시 별도 판정
  - 저알부민혈증·파라단백질혈증·고Mg/Ca·리튬·측정 오류 감별 안내
  - 보정 후에도 < 6이면 추가 경고
  - 플로우차트 AG 행, 최종 카드, primCause 모두 반영
- **Albumin 보정 공식 표시** — Figge-Mydosh-Fencl 공식 + 계산 과정 명시
  - 보정량 ±2 이상: 명시 표시 / ±2 미만: 간단 안내

## 주요 기능

### 산-염기 분석
- Henderson-Hasselbalch 검증
- pH 평가 (산혈증/알칼리혈증)
- 일차장애 결정 (4가지) — 호흡성/대사성 판정 로직 대칭화 (v5.9)
- 보상기전 평가 (Winters / Javaheri / 호흡성 급성·만성)
  - 보상 확신도(확정 vs 불확실)를 최종요약·플로우차트까지 일관 반영 (v5.10)
- 음이온차 (AG) — Albumin 보정 (Figge 공식)
- Delta ratio 계산 및 해석

### 산소화 평가
- PaO₂ / SaO₂ 평가
- P/F ratio (Berlin ARDS 기준)
- D(A-a)O₂ (폐포-동맥 산소 분압차)
- PaO₂-SaO₂ 불일치 감지

### 전해질 및 임상화학
- K⁺ / Glucose / BUN / Creatinine
- Phosphate (Inorganic phosphorus)
- Serum Osmolality → Osmol gap
- Albumin (AG 보정용)
- Lactate

### 결과 제시
- 단계별 해석 (I 산소화 → II 산-염기 → III 전해질)
- 해석 경로 플로우차트 (SVG)
- 전해질 균형도 그래프 (양이온/음이온 상하 배치)
- 임상 패턴 인식 (DKA, 패혈성 쇼크 등)
- PDF 출력

### Claude Vision 자동 입력
- 검사 결과 사진 → 자동 입력 (API 키 필요)
- PC: 파일 선택 / 드래그&드롭 / 클립보드 붙여넣기 (항상 누적, v5.8)
- 모바일: 카메라 촬영 (여러 장 누적 후 분석, 촬영 즉시 백그라운드 압축으로 속도 개선 — v5.11)

## 사용법

1. GitHub Pages URL 접속
2. (선택) ⚙ 설정 → Claude API 키 입력 (사진 자동 입력 활성화)
3. I. 산소화 지표, II. 산-염기 지표, III. 전해질 입력
4. **해석하기** 버튼 클릭
5. 단계별 결과 및 플로우차트 확인
